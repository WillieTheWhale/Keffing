These local photographs were downloaded for visual study. `sources.json` records
their URLs; the photographs and contact sheets are excluded from version control.
The website uses eight original models and a simplified derivative of Apple’s
AirPods Pro 3 USDZ. The retained `airpods-low-poly.json` is the editable geometry
build input. `switch-home-original.png` is the actual Nintendo HOME screenshot
used to generate the Switch screen texture. Their URLs are in `sources.json`.

The silver CF-SX1 chassis photos come from PC Watch's 2012 CF-SX1 review. The
Mariana Blue swatch (`blue-options-16.jpg`) comes from the same-era Panasonic
SX2 promotion and is used only as a finish reference; chassis geometry follows
the CF-SX1. See the full reference notes in `artwork/hardware/README.md`.
